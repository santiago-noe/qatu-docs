Sigue docs/04-arquitectura.md y docs/03-dominio.md. Stack fijo: monorepo pnpm + Turborepo; TypeScript estricto; API NestJS REST /v1 con OpenAPI; esquemas Zod en packages/contracts; PostgreSQL 16 con PostGIS y btree_gist; Drizzle ORM con migraciones versionadas; Redis + BullMQ para jobs, timeouts y outbox relay; almacenamiento S3-compatible (MinIO local, R2 en producción) con URLs prefirmadas; web Next.js App Router + Tailwind + shadcn/ui como PWA; auth por OTP de teléfono con JWT de acceso corto y refresh rotativo en cookie httpOnly; WebSockets con Socket.IO + adaptador Redis; tests con Vitest, Supertest + Testcontainers y Playwright; docker compose para desarrollo; GitHub Actions para CI. Estructura de módulo: domain / application / infrastructure / http. Incluye en el plan: modelo de datos con índices y restricciones, contratos de API, eventos de dominio emitidos y consumidos, jobs programados, permisos por rol, parámetros que van a platform_settings, y el plan de pruebas. No agregues dependencias fuera de este stack sin justificarlas en research.md.
